Command constants recovered from the unpacked BMWScan140.exe.

Method: every `call` to the three mode-setting wrappers was located by scanning the image for
its relative-call encoding, then the bytes before each site were scanned backwards for the last
`mov ecx, imm32` - which the Delphi register convention puts in the frame's command field - and
`mov dl, imm8`, which lands in the parameter field.

This is a heuristic, and individual rows may be wrong. The method as a whole is corroborated:
the two commands actually captured from the running software land in exactly the mode their line
settings imply - 0x83F0 in mode 2 at 9600 8E1, which is DS2, and 0x41AA in mode 3 at 19200 8N1.

Mode selects how the reply's length is read (FUN_006ccdd4):
  mode 1  length at byte index 2
  mode 2  length at byte index 1   <- DS2
  mode 3  length at byte index 3, plus 5
